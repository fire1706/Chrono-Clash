# Étape M2 — L'armée

## Ce qui est en place

**Données (`data/`)** — les règles chiffrées sont sorties du code :
- `troops.json` : les 3 types de troupes (prix, gains, fréquence des bulles, espacement…) avec leurs statistiques pour les 8 ères, les 8 chefs et les étoiles.
- `eras.json` : noms, seuils de ★ et années des 8 ères.
- `tuning.json` : nombre de bulles sur la carte, vitesse d'apparition, etc.
Ces fichiers acceptent les `// commentaires`. Ils sont intégrés au cœur : après une modification, il suffit de recompiler (marteau de Godot).

**Cœur (`src/ChronoClash.Core`)**
- `Data/GameData` : lit et vérifie les fichiers JSON.
- `Entities/Unit`, `Entities/Bubble`, `Entities/IBody` : troupes, bulles, et tout ce qui occupe de la place.
- `Formations/FormationTemplate` : un dessin 17 × 13 et les 4 formations de départ (Ligne, Carré, Coin, Colonne).
- `Formations/FormationLayout` : transforme un dessin en places concrètes, en l'agrandissant avec l'armée (port de computeSlots).
- `Systems/FormationSystem` : donne sa place à chaque troupe sans qu'elles se croisent.
- `Systems/UnitMovementSystem` + `UnitTuning` : déplacement des troupes, séparation, anti-blocage (chemin, place rapprochée, retour près du chef).
- `Systems/BubbleSystem` : apparition et ramassage des bulles et des étoiles.
- `Systems/Recruitment` : ajout de troupes (bulle, achat, test).
- `Simulation/SpatialGrid` : recherche rapide des voisins.
- Nouveaux ordres : achat, choix de formation, envoi d'un dessin, et `DebugSpawnTroops` (F4, refusé si la partie n'autorise pas les triches).

**Jeu Godot (`game/scripts`)**
- `Presentation/TroopRenderer` + `UnitDrawings` + `UnitVisualRegistry` : les troupes (dessin par défaut ou image du graphiste), en pastilles quand on dézoome.
- `Presentation/BubbleRenderer` : les bulles et les étoiles.
- `Presentation/EffectsLayer` : textes flottants et cercles au ramassage.
- `UI/GameHud` : ressources, effectifs, boutons d'achat et de formation, messages.
- `UI/FormationEditor` + `FormationGridCanvas` + `FormationPreviewCanvas` : l'éditeur de formation avec aperçu en direct.
- `Persistence/FormationStore` : tes formations sont enregistrées et retrouvées à chaque partie.

## Comment vérifier

1. Ramasser des bulles : une troupe apparaît, avec un texte « +1 Guerrier · +4 ◆ ». Les étoiles donnent des ★.
2. Les troupes suivent le chef en formation et pivotent avec lui ; elles contournent l'eau et les rochers.
3. **4 / 5 / 6** achètent des troupes (message si les ressources manquent).
4. **Tab** ou **7 8 9 0** changent de formation ; **F** ouvre l'éditeur : peindre, voir l'aperçu, « Utiliser cette formation ».
5. **F4** ajoute 20 troupes pour tester une grosse armée ; dézoomer pour voir les pastilles.
6. `dotnet test tests/ChronoClash.Core.Tests` : tous les tests passent.

## Où changer quoi

| Je veux… | Fichier |
|---|---|
| Le prix, les gains ou la fréquence d'une troupe | `data/troops.json` |
| Plus ou moins de bulles sur la carte | `data/tuning.json` |
| L'espacement des troupes en formation | `data/troops.json` (champ `spacing`) |
| Les formations de départ | `src/ChronoClash.Core/Formations/FormationTemplate.cs` |
| La réactivité des troupes, l'anti-blocage | `src/ChronoClash.Core/Systems/UnitTuning.cs` |
| Le dessin d'une troupe | `game/scripts/Presentation/UnitDrawings.cs`, ou une image dans `game/assets/art/units/` |
| L'aspect des bulles | `game/scripts/Presentation/BubbleRenderer.cs` |
| L'interface (boutons, panneau) | `game/scripts/UI/GameHud.cs` |
| Le zoom à partir duquel les troupes deviennent des pastilles | `game/scripts/Presentation/TroopRenderer.cs` (`SimpleDrawZoom`) |
